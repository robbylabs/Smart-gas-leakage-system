About the System

Smart Gas Leakage Detection and Alert System - Specifications and Documentation.

Project Specifications

This Gas Monitoring system utilizes IoT gas sensors (such as the MQ-2/MQ-5/MQ-135) to measure real-time concentrations of liquefied petroleum gas (LPG), butane, propane, methane, alcohol, and smoke in the ambient air.

The controller processes PPM (Parts Per Million) counts and sends updates to the central Flask database. In an industrial setup, levels exceeding safety boundaries alert onsite supervisors through audio and email alarms.

System Thresholds

  • Safe Zone: 0 - 200 PPM Normal
  • Warning Zone: 201 - 350 PPM Monitor Closely
  • Danger Zone: Above 350 PPM Critical Alert

System Info

Core Backend: Python Flask
Database: SQLite (SQLAlchemy)
UI Styles: Bootstrap 5 & Vanilla CSS
Telemetry Refresh: Every 2 Seconds (Fetch API)
